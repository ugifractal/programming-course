# lesson-1.md

## 1. Konsep Dasar Bahasa Pemrograman
* **Apa itu Bahasa Pemrograman:** Jembatan komunikasi antara instruksi manusia dan logika komputer.
* **Paradigma Eksekusi:** Perbedaan umum antara *Compiled* vs *Interpreted* (bagaimana komputer membaca dan menjalankan kode).
* **High-Level vs Low-Level:** Alasan bahasa modern dibuat lebih dekat dengan bahasa manusia (*developer-friendly*).

## 2. Persiapan Environment & Tools
* **Compiler / Interpreter:** Fungsi utama *engine* pengolah kode di dalam sistem operasi.
* **Tools Kerja:** 
  * **Interactive Console:** Tempat eksperimen dan eksekusi kode langsung per baris.
  * **Text Editor / IDE & File Script:** Menulis, menyimpan, dan mengelola struktur kode sumber (*source code*).
* **Alur Eksekusi:** Menjalankan file kode pertama melalui terminal / command prompt.

## 3. Variabel
* **Konsep Variabel:** Wadah berlabel di dalam memori untuk menyimpan nilai/data.
* **Mekanisme Assignment:** Cara meletakkan nilai ke dalam variabel (operator `=` / penamaan nilai).
* **Aturan & Konvensi Penamaan:** Batasan karakter, sensitivitas huruf besar/kecil (*case sensitivity*), serta gaya penamaan (*snake_case* vs *camelCase*).

## 4. Tipe Data
* **Nilai & Tipe Data:** Jenis-jenis informasi yang dapat disimpan ke dalam variabel.
* **Tipe Data Utama:**
  * **Text / String:** Karakter dan kalimat.
  * **Number:** Integer (angka bulat) & Float (angka desimal).
  * **Boolean:** Nilai kebenaran (`true` / `false`).
  * **Array / List:** Koleksi data terurut berdasarkan indeks.
  * **Hash / Dictionary / Object:** Koleksi data berbentuk pasangan kunci dan nilai (*key-value pairs*).
* **Input / Output Dasar:** Cara mencetak/menampilkan nilai variabel ke layar dan membaca input.

## 5. Interpolasi String
* **Konsep:** Menyisipkan nilai variabel atau ekspresi secara dinamis ke dalam teks.
* **Perbandingan Metode:** Penggabungan teks manual (*String Concatenation*) vs Interpolasi (*String Interpolation*).
* **Aturan Sintaks:** Penanganan karakter khusus dan perbedaan teks statis vs teks dinamis.

## 6. Kondisional & Pengambilan Keputusan
* **Logika Komparasi & Boolean:** Operator perbandingan (`==`, `>`, `<`, `!=`) dan logika (`AND`, `OR`, `NOT`).
* **Struktur Alur Kontrol:**
  * Percabangan tunggal (`if`).
  * Percabangan ganda / bertingkat (`if - else` / `else if`).
  * Percabangan multi-kondisi (`case - when` / `switch - case`).

## 7. Perulangan / Looping
* **Tujuan Looping:** Otomatisasi proses yang berulang tanpa perlu menulis ulang kode.
* **Loop Berbasis Kondisi:** Perulangan yang berjalan selama suatu kondisi bernilai benar (`while`).
* **Loop Berbasis Hitungan / Iterasi:** Perulangan berdasarkan urutan angka atau koleksi data (`for` / `each`).
* **Kontrol Perulangan:** Mekanisme menghentikan (*break*) atau melompati iterasi saat ini (*continue* / `next`).
